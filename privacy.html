Privacy Policy — webmcp Chrome Extension

Effective Date: November 2026
Summary: webmcp does not operate any backend server, does not collect telemetry or analytics, and does not sell or share your personal data. All configuration and API keys stay locally in your browser (chrome.storage.local) and are sent directly from your browser only to the AI provider you explicitly configure (Google Gemini, Anthropic Claude, or OpenAI).

1. Overview & Single Purpose

webmcp is a client-side Chrome Extension that enables users to discover, inspect, and execute WebMCP (Web Model Context Protocol) tools exposed by webpages using natural language prompts powered by the user's own API key from Google Gemini, Anthropic Claude, or OpenAI.

2. Data Stored Locally on Your Device

All extension data is stored exclusively on your local device using Chrome's built-in chrome.storage.local API:

  • AI Provider API Keys: Any API keys you enter for Google Gemini, Anthropic Claude, or OpenAI are saved locally in chrome.storage.local. They are never transmitted to the extension developer or any third party other than the corresponding AI provider you selected.
  • User Preferences: Your chosen AI provider, selected model ID, UI theme (Light/Dark/System), and interface language preference.
  • Local Prompt History: Up to 100 of your most recent prompt inputs are stored locally in chrome.storage.local so you can recall previous prompts with the Up/Down arrow keys.

3. How Webpage & User Data Is Processed

When you open the webmcp Side Panel or Popup and submit a natural language prompt:

  • WebMCP Tool Discovery: The extension inspects the currently active tab for WebMCP tool definitions registered via navigator.modelContext / document.modelContext or declarative HTML forms (<form toolname="...">).
  • Direct AI Provider Requests: When you send a prompt, your prompt text, the active page's title and URL, the schemas of the discovered WebMCP tools on that page, and the outputs of any executed WebMCP tool calls are sent directly from your browser over HTTPS to the official API endpoint of your selected provider:
    • Google Gemini API (https://generativelanguage.googleapis.com)
    • Anthropic Claude API (https://api.anthropic.com)
    • OpenAI API (https://api.openai.com)
  • No data is ever routed through any intermediate proxy or server owned by the extension developer.

4. Permissions Used & Why

  • storage: Stores your API keys, model selection, UI preferences, and local prompt history in chrome.storage.local.
  • activeTab & scripting: Discovers and executes WebMCP tools registered in the active webpage's MAIN JavaScript world when you interact with the extension.
  • sidePanel: Displays the webmcp assistant UI inside Chrome's native side panel alongside the webpage.
  • tabs: Detects active tab changes and page navigation events so the displayed list of WebMCP tools stays synchronized with the current tab.
  • <all_urls> (Host Permission): Allows the extension to detect WebMCP tools on any WebMCP-enabled website you visit and connect directly to your chosen AI provider's API endpoint.

5. Data Sharing, Sale, and Compliance

We do not collect, transmit, store, sell, or rent any user data on external servers. In accordance with the Chrome Web Store User Data Policy and Limited Use requirements:

  • We do not transfer or sell user data to third parties, data brokers, or advertising networks.
  • We do not use or transfer user data for serving advertisements, creditworthiness, or lending purposes.
  • Any data sent to Google Gemini, Anthropic Claude, or OpenAI is governed by your own account and the respective privacy policy and terms of service of the provider whose API key you supply.

6. User Control & Data Deletion

Because all data is stored locally in your browser:

  • You can clear or replace your API key at any time in the extension's Settings panel.
  • Uninstalling the webmcp extension from Chrome automatically and permanently deletes all locally stored data in chrome.storage.local.

7. Contact & Open Source Transparency

webmcp is open source. You can inspect the complete source code or report questions and issues on GitHub at: https://github.com/AJLoveChina/webmcp-extension.
