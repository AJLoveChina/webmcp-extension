2. Permission Justifications Chrome Web Store Privacy Tab

Copy and paste each justification below into the corresponding permission field in the Chrome Web Store Developer Dashboard:

storage Justification

Required to locally store the user's AI provider settings (selected provider, model ID, UI theme/language preference, user-entered API keys for Gemini, Claude, or OpenAI, and recent prompt history) in chrome.storage.local on the user's device so settings persist across browser sessions without any external backend server.

activeTab Justification

Required to inspect and interact with the currently active tab when the user opens the webmcp side panel or popup, allowing the extension to discover registered WebMCP tools (navigator.modelContext / document.modelContext and declarative WebMCP forms) and execute user-requested WebMCP tool calls on the active page.

scripting Justification

Required to query and execute WebMCP tools in the webpage's MAIN JavaScript world via chrome.scripting.executeScript, enabling direct interaction with the page's runtime navigator.modelContext / document.modelContext API and declarative <form toolname="..."> elements when triggered by the user.

sidePanel Justification

Required to display the persistent webmcp conversational assistant and WebMCP Tool Inspector in Chrome's native Side Panel (chrome.sidePanel), allowing users to view discovered page tools and run natural language actions alongside the webpage without covering page content.

tabs Justification

Required to query the active tab and listen for tab switches or page navigation events (chrome.tabs.onActivated and chrome.tabs.onUpdated) so the Side Panel automatically refreshes the list of available WebMCP tools whenever the user switches tabs or navigates to a new URL.

Host Permission (<all_urls>) Justification

Required because any website on any domain can implement the open WebMCP standard (imperative navigator.modelContext.registerTool APIs or declarative <form toolname="..."> HTML forms), and the extension also makes direct client-side requests from the browser to the user's configured AI provider endpoints (generativelanguage.googleapis.com, api.anthropic.com, and api.openai.com). Injecting the WebMCP bridge across URLs enables automatic tool discovery and execution on any WebMCP-enabled website the user visits.
